# Sample Superstore Sales Analysis

## Project Overview
This project analyzes retail sales and profit data using Microsoft Excel. The goal is to identify sales trends, compare regional performance, and understand which product categories generate the most profit.

## Tools Used
- Microsoft Excel
- PivotTables
- Charts and data visualization
- GitHub

## Business Questions
1. Which region generates the highest sales?
2. Which product category generates the highest profit?
3. How do sales change over time?
4. Which areas of the business could benefit from further analysis?

## Key Findings
- **Highest-sales region:** West
- **Total sales:** $2,297,200.86
- **Most profitable category:** Technology
- **Technology profit:** $145,454.95
- **Office Supplies profit:** $122,490.80
- **Furniture profit:** $18,451.27

## Process
1. Imported the Sample Superstore dataset into Excel.
2. Checked the data for missing values and duplicate Row IDs.
3. Created PivotTables to summarize sales by region and profit by category.
4. Created a chart comparing profit across product categories.
5. Analyzed monthly sales trends and developed an Excel dashboard.

## Project Files
The Excel workbook and dashboard will be added to this repository.

## Conclusion
The initial analysis shows that the West region has the highest sales and Technology has the highest profit among the three product categories. Further analysis could investigate monthly trends, regional profitability, and product-level performance.
